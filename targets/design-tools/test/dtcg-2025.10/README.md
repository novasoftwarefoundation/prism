# DTCG 2025.10 JSON Schema

The JSON Schema of the [Design Tokens Format Module 2025.10](https://www.designtokens.org/tr/2025.10/format/), copied unchanged from `schemas/src/2025.10/` of [design-tokens/community-group](https://github.com/design-tokens/community-group/tree/882ebd6716abef9a46d8ef5fb12e82009d6cee2e/schemas/src/2025.10) at commit `882ebd6716abef9a46d8ef5fb12e82009d6cee2e`. designtokens.org publishes only the top file (`https://www.designtokens.org/schemas/2025.10/format.json`), whose references to the other files don't resolve there, so the checks keep the whole set here.
